# Wrap Atölyesi

Tesla Paint Shop için sıfırdan wrap tasarlama uygulaması. App Store gerektirmez, iPhone'da Ana Ekrana eklenerek kullanılır ve ilk açılıştan sonra internetsiz çalışır.

## Yayınlama (GitHub Pages, ücretsiz)
1. github.com'da yeni bir depo aç (ör. `wrap-atolyesi`).
2. Bu klasörün içindeki tüm dosyaları depoya yükle (`t` klasörü dahil).
3. Settings → Pages → Branch: `main`, klasör: `/ (root)` → Save.
4. Birkaç dakika sonra adres: `https://KULLANICIADI.github.io/wrap-atolyesi/`

## iPhone'a kurulum
1. Adresi **Safari**'de aç.
2. Paylaş → **Ana Ekrana Ekle**.
3. Uygulamayı bir kez internet varken aç; sonrasında internetsiz de çalışır.

## Wrap'i araca yükleme
- Uygulamada **PNG indir** → **PNG'yi kaydet** → **Dosyalar'a Kaydet**.
- Tesla uygulaması (4.59+): Creations → Wrap → Upload.
- USB: exFAT/FAT32 bellek, kökte `Wraps` klasörü.
- Araçta: Toybox → Paint Shop → Wraps.

Şablonlar Tesla'nın resmi github.com/teslamotors/custom-wraps deposundandır.
